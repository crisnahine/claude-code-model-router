# Code of conduct

Model Router follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in this repository, its issues and pull requests, and the project's Discord server.

To report a problem, use the repository's [private advisory form](https://github.com/crisnahine/claude-code-model-router/security/advisories/new). A report there reaches the maintainer alone, who reads every one.
